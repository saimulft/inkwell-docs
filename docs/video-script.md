# Walkthrough video script (as recorded)

Video: https://vimeo.com/1248383864/b9bb502a27 (3 min 39 s). Screens were captured from the live app by the agent in BrowserOS; the narration is the ElevenLabs voice Dylan reading this script.

| #   | Voiceover                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | On screen                                                                                            |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 1   | This is Inkwell, a lightweight document editor I built for the Ajaia take-home. I'll show the main flow, what works end to end, what I cut, the key decisions, and how I used AI. The narration is an AI voice reading my script.                                                                                                                                                                                                                                                                                                           | Title card: Inkwell, Ajaia take-home, Saimul Islam, "AI voice narration"                             |
| 2   | Sign-in uses three seeded demo accounts with no passwords, so switching users takes one click. The session is still real: a hashed token in Postgres and an http-only cookie. On the home page, my documents and the ones shared with me are listed apart, and shared ones show the owner and my role.                                                                                                                                                                                                                                      | Sign-in page, cursor picks Alice, home page with Owned by me and Shared with me                      |
| 3   | Now the core flow. I create a document and rename it. I can use headings, bold, italic, underline and lists. It saves on its own when I pause, and the status says Saved. After a reload, everything comes back as it was. The server stores the editor's structured content and checks it against the editor's own schema.                                                                                                                                                                                                                 | New document, title typed, heading, bold, italic, underline and a bullet list typed, "Saved", reload |
| 4   | File upload turns a text, Markdown or Word file into a new document. Headings, lists and bold text carry over. The page states the limits: those three file types, up to four megabytes, which keeps uploads under Vercel's request limit.                                                                                                                                                                                                                                                                                                  | Import a file, a Markdown file picked, the new document with its heading and lists                   |
| 5   | Sharing has an owner and three roles. Viewers can read, commenters can also comment, and editors can also edit. I'll give Bob edit access. An email that doesn't belong to a user gets a clear error. One permission function on the server checks every request, and people without access get a not-found page.                                                                                                                                                                                                                           | Share dialog, Bob added as Editor, role menu, unknown email error                                    |
| 6   | Bob opens the document from his own session. His avatar appears, and it changes to editing while he types. His saves reach my screen within a few seconds. Saves are versioned. If we both save from the same version, the second save gets a conflict, and I choose to load his version or keep mine. Nothing is overwritten silently.                                                                                                                                                                                                     | Bob's avatar in the header, "editing", his line arrives, conflict banner, Keep mine                  |
| 7   | Version history keeps each editing session as a version. I can preview an old one and restore it, and the restore is saved as a new version, so it can be undone. Documents export to Markdown, or to PDF through the print dialog. Carol is a commenter: her page is read-only, but she can comment on selected text.                                                                                                                                                                                                                      | History panel, preview, restore, download menu, Carol's read-only view with comments                 |
| 8   | What I cut on purpose: real-time co-editing with CRDTs. It needs a long-running WebSocket server, which Vercel functions don't offer, and it would have taken most of the timebox. I also skipped passwords, comment replies, suggestion mode and images. With a few more hours, I'd add Y-J-S co-editing and live cursors.                                                                                                                                                                                                                 | Architecture note in the GitHub repo: what I cut                                                     |
| 9   | Key decisions: Next.js with the Tiptap editor, and Postgres through Drizzle. Locally it runs on an embedded Postgres, so there's no setup, and the tests run real SQL. Production uses Neon. The public GitHub repo deploys to Vercel on every push, and each build runs the migrations and a seed that's safe to run twice.                                                                                                                                                                                                                | README and repo on GitHub                                                                            |
| 10  | I built this with Claude Code as my pair. It scaffolded the app and drafted the data layer, the screens and the tests. I made the calls: no real-time design on this host, a lower upload limit after checking Vercel's cap, and a read-only preview instead of injected HTML. I verified with strict TypeScript, lint, thirty-two tests, curl checks of every error path, and a live smoke test. That test caught a sign-in bug that only happened in production, and it's fixed. A browser agent also captured the screens in this video. | AI workflow note, terminal card with the real test run and curl status codes                         |
